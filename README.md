# Salesforce API Testing & Automation

## Project Overview
This project focuses on testing and automating Salesforce REST APIs using Postman, Playwright, and TypeScript. It demonstrates API authentication, CRUD operations, response validation, and verification of expected API behavior.

The project was developed to practice API testing concepts and understand how Salesforce records can be managed and validated through REST API requests.

## Objectives
- Understand Salesforce REST API testing.
- Implement OAuth 2.0 authentication to access protected APIs.
- Perform CRUD operations on Salesforce Account records.
- Validate HTTP status codes and API response data.
- Automate API test scenarios using Playwright and TypeScript.

## Tools & Technologies
- **Playwright:** API test automation
- **TypeScript:** Test scripting
- **Postman:** API request execution and manual validation
- **Salesforce REST API:** Account record management
- **OAuth 2.0:** API authentication
- **Git & GitHub:** Version control and project hosting

## Testing Scope

### 1. Authentication
- Used OAuth 2.0 authentication to obtain access to Salesforce APIs.
- Used the access token to authorize API requests.
- Verified authenticated API request behavior.

### 2. CRUD Operations
- **GET:** Retrieve Account records and validate returned data.
- **POST:** Create new Account records.
- **PATCH:** Update existing Account records.
- **DELETE:** Delete Account records.

### 3. Response Validation
- Checked HTTP status codes.
- Validated response data and expected values.
- Verified Account creation, retrieval, updates, and deletion.
- Used assertions to check expected API behavior.

### 4. API Automation
- Created API automation scripts using Playwright and TypeScript.
- Used requests and assertions to validate API responses.
- Organized automated checks into structured test cases.

## Key Learning Outcomes
- Understanding REST API testing workflows.
- Working with OAuth 2.0 authentication.
- Performing CRUD operations on Salesforce records.
- Writing automated API tests using Playwright.
- Validating API responses and expected application behavior.
